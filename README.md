# HMN Data Collector v1.7.5 · OHLCV Only

Bitget USDT Futures native OHLCV 수집/검증 도구입니다.

지원 시간봉: 1m, 5m, 15m, 30m, 1H, 4H, Bitget 1D.

## v1.7.5 핵심
- v1.7.4의 OHLC 이상봉 교차검증 정지처럼 보이는 문제를 수정했습니다.
- 기존에는 이상봉마다 V2/V3를 여러 번 재조회해 이상봉 수가 많으면 API 호출이 수천~수만 회까지 증가할 수 있었습니다.
- v1.7.5는 이상봉이 존재하는 구간을 **페이지 단위로 일괄 교차검증**합니다.
- 1m 기본 수집은 V3 Historical Candles를 유지하고, 이상봉 교차검증은 V2 원본 페이지를 사용합니다.
- 동일 timestamp의 정상 원본 봉이 확인된 경우에만 교체합니다. High/Low 등 가격을 임의 수정하지 않습니다.
- 교차검증 진행 중 API 페이지 수 / 대상 / 복구 / 미복구 수를 계속 표시합니다.
- 미복구 OHLC 오류가 남으면 공식 Bitget Futures Candlestick CSV로 덮어쓴 뒤 재검증할 수 있습니다.
- `다운로드 가능한 전체기간 확인` 기능을 유지합니다.

장기간 1m은 수백만 봉이 될 수 있으므로 월별/분기별 수집을 권장합니다.
