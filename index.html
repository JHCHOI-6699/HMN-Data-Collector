HMN Data Collector v1.7.2 · OHLCV Only

Order Flow 기능을 제거한 OHLCV 전용 버전입니다. 선택 기간 전체를 Bitget Historical Candles API로 수집하고, 중복·누락·OHLC 오류를 검증한 뒤 검증 통과 데이터만 CSV로 다운로드합니다.

1. OHLCV 수집 범위

기본값은 BTCUSDT 2019-07-10 ~ 2026-07-31입니다. 5m·15m·30m·1H·4H·1D를 지원합니다. 날짜는 필요하면 변경할 수 있습니다. 1D는 Bitget UTC+8 일봉 경계를 사용합니다.

2. 전체기간 OHLCV 수집·검증

Bitget Historical Candles API를 과거 방향으로 반복 조회합니다. 확인된 Bitget 최초 제공 봉보다 앞선 요청 구간은 가짜 누락으로 만들지 않고 API 제공 전 구간으로 분리합니다. 실제 제공범위 안의 중복·누락·OHLC 오류가 모두 0이면 다운로드할 수 있습니다. 5m 전체기간은 수십만 봉이라 수집 시간이 길고 브라우저 메모리를 많이 사용하므로 PC 브라우저 사용을 권장합니다.

3. 과거 OHLCV CSV 보완 — 필요한 경우에만

API가 오래된 구간까지 내려가지 못한 경우에만 사용합니다. Bitget History data download → Futures → Candlestick CSV를 압축 해제해 선택하세요. 현재 시간봉과 timestamp가 일치하는 봉만 병합하고 중복 제거 후 전체기간을 다시 검증합니다.

CSV 형식

timestamp, datetime_utc, open, high, low, close, volume_base, volume_quote

CSV 다운로드는 Bitget의 확인된 최초 제공 봉부터 요청 종료일까지 예상 봉 수가 모두 존재하고, 중복·내부 누락·OHLC·숫자·음수 거래량 오류가 모두 0일 때만 활성화됩니다. 최초 제공 봉보다 앞선 시간은 데이터 누락으로 간주하지 않습니다.
