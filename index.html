HMN Data Collector v1.5.1

Bitget USDT Futures를 선택한 시간봉 그대로 수집합니다. API가 더 오래된 OHLCV를 반환하지 못하면 공식 Candlestick CSV를 추가해 같은 시간봉으로 자동 병합할 수 있습니다. Order Flow도 선택 시간봉과 같은 버킷으로 병합합니다.

검증 결과

Order Flow 포함 시 CSV 열: timestamp, datetime_utc, open, high, low, close, volume_base, volume_quote, taker_buy_base, taker_sell_base, delta_base, buy_ratio, sell_ratio, total_active_base, cvd

과거 OHLCV 보완 — API 시작점보다 더 오래된 기간

Bitget 과거 캔들 API가 요청 시작일까지 내려가지 못하면 수집된 최신 구간은 보존합니다. Bitget 공식 History data download의 Futures Candlestick CSV를 내려받아 아래에서 복수 선택하면 현재 선택 시간봉과 timestamp 기준으로 병합·중복제거·재검증합니다.

과거 Order Flow 보완 — 필요한 경우에만

OHLCV는 선택 기간 전체를 API 페이지네이션으로 수집할 수 있습니다. 반면 Active Buy/Sell 공개 API는 과거 start/end 페이지네이션이 없으므로, 오래된 전체기간 Order Flow가 필요한 경우 Bitget 공식 Futures Transaction History CSV를 한 번 가져와야 합니다. 가져온 체결은 현재 선택한 시간봉으로 직접 집계하며 1H를 중간 Master로 만들지 않습니다.
