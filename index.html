HMN Data Collector v1.6.0

장기 연구용 전용 버전입니다. OHLCV 전체기간과 Order Flow 가능기간을 분리해 수집하고, 두 데이터가 겹치는 구간을 timestamp 기준으로 병합·검증합니다.

1. 연구 범위 설정

기본값: OHLCV 2019-07-10~2026-07-31 / Order Flow 2021-05-18~2026-07-31. 최종 병합 CSV는 Order Flow 기간만 생성합니다.

2. OHLCV 전체기간 수집·검증

Bitget Historical Candles API를 과거 방향으로 페이지네이션합니다. API가 요청 시작일까지 내려가지 못하면 이미 받은 구간을 보존하고 아래 Candlestick CSV 보완 기능을 사용합니다.

3. 과거 OHLCV 보완 — 필요한 경우에만

Bitget History data download → Futures → Candlestick CSV를 압축 해제한 뒤 복수 선택합니다. 현재 시간봉과 timestamp가 일치하는 봉만 병합하고 중복 제거 후 다시 검증합니다.

4. Order Flow 원본 체결 CSV 집계

Bitget History data download → Futures → Transaction history → Daily 파일을 사용합니다. 공식 헤더 timestamp, trade_id, price, side, volume(quote), size(base)를 지원합니다. 파일은 여러 번 나눠 가져올 수 있고 집계 결과는 브라우저 IndexedDB에 저장됩니다.

대용량 파일은 한 파일씩 스트리밍 처리합니다. 같은 파일을 다시 선택하면 파일명·크기·수정시간 기준으로 중복 가져오기를 건너뜁니다. 서로 다른 파일의 날짜 구간이 겹치지 않도록 주의하세요.

5. 최종 병합·검증

병합 기준은 OHLCV timestamp입니다. Order Flow 기간의 OHLCV 모든 봉에 Order Flow 버킷이 있어야 통과합니다. CVD는 병합 시작점에서 0으로 시작해 순차 누적합니다.

병합 CSV 열: timestamp, datetime_utc, open, high, low, close, volume_base, volume_quote, taker_buy_base, taker_sell_base, delta_base, buy_ratio, sell_ratio, total_active_base, cvd
