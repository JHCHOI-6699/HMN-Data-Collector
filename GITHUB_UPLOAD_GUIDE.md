# GitHub upload guide — v1.7.5

1. Open the existing `HMN-Data-Collector` repository.
2. `Code` → `Add file` → `Upload files`.
3. Upload these four files from this package:
   - `index.html`
   - `README.md`
   - `CHANGELOG.md`
   - `GITHUB_UPLOAD_GUIDE.md`
4. Commit message example: `Update HMN Data Collector to v1.7.5`.
5. Do not change the existing GitHub Pages `main / (root)` setting.
6. Wait for `Actions` → `pages build and deployment` to show a green check.
7. Open the existing Pages URL and press `Ctrl + F5`.
8. Confirm the page title shows `HMN Data Collector v1.7.5 · OHLCV Only`.
